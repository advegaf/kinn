# Consent to record and use voice (Kinn, HackTX 2026)

Print one copy per person (or both languages on one page). Sign before recording.

## English

I, ______________________, agree that the Kinn team may:

1. Record my voice and my image for a hackathon project called Kinn.
2. Use a short sample of my voice to create a computer copy of my voice. The copy is used only to read my own messages to my family in another language.
3. Show these recordings in a 2 to 3 minute demo video submitted to the HackTX 2026 Meta track. The video and the project code will be public.
